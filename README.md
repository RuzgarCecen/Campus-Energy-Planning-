- About the Project

This web-based campus energy system planning tool was developed with four teammates as our capstone project in the Software Engineering program at Bahçeşehir University. It presents energy demand, photovoltaic (PV) generation, and battery storage data through interactive dashboards.

- My Contribution — İsmail Rüzgar Çeçen

I was responsible for **frontend development and user interface (UI) design**.

- Built the frontend architecture using React, Vite, and Tailwind CSS.
- Developed reusable UI components.
- Created interactive dashboards with Recharts to visualize energy data and key performance indicators (KPIs).
- Designed clear, user-friendly interfaces to make complex technical data easier to understand.
- Prepared API-ready data structures for backend integration.
